# 2. Project Overview

NexaMart AI is a web-based marketplace where multiple vendors can register, manage stores, and sell physical products through a single platform.

Customers can browse products, manage shopping carts, make secure purchases using M-Pesa, track orders, leave reviews, and manage their accounts.

Administrators oversee the platform by managing users, approving vendors, moderating products, generating reports, and maintaining overall system integrity.

---

# 3. Problem Statement

Many small businesses struggle to establish an online presence due to the high cost and technical complexity of developing individual e-commerce websites.

Customers also face challenges when purchasing from multiple independent vendors because there is no centralized platform offering a consistent shopping experience.

NexaMart AI addresses these challenges by providing one secure marketplace where multiple vendors can operate while customers enjoy a unified shopping experience.

# 8. System Architecture

The system follows a modern client-server architecture.

The frontend communicates securely with Supabase services for authentication, database operations, storage, and server-side functions.

This architecture improves scalability, maintainability, and security while reducing infrastructure complexity.

---

# 9. Database Design

The database is implemented using PostgreSQL and follows Third Normal Form (3NF).

Key entities include:

- Profiles
- Vendors
- Categories
- Products
- Product Images
- Shopping Carts
- Orders
- Reviews
- Wishlists
- Notifications
- Audit Logs

Relationships are enforced through primary keys, foreign keys, constraints, and Row Level Security policies.
